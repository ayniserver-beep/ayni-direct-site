# Ayni Direct — sitio OAuth

Sitio estático preparado para la página principal, política de privacidad y condiciones del conector personal Ayni Direct.

## Rutas públicas previstas

- `https://ayni.is-a.dev/`
- `https://ayni.is-a.dev/privacy.html`
- `https://ayni.is-a.dev/terms.html`

## Ruta de publicación propuesta

1. Crear un repositorio público de GitHub Pages para el sitio.
2. Solicitar gratuitamente `ayni.is-a.dev` en `is-a-dev/register`.
3. Publicar `ayni.is-a.dev` como CNAME hacia GitHub Pages.
4. Verificar la propiedad del sitio en Google Search Console.
5. Completar el método de verificación que indique Google.
6. Registrar `ayni.is-a.dev` como dominio autorizado en Google Auth Platform.
7. Usar las tres rutas anteriores en la información de marca.

La publicación, la creación de repositorios y las solicitudes externas requieren autorización expresa del propietario.
